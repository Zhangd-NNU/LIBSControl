# LIBS Dawa 激光器上位机

本软件用于通过 Windows 电脑控制北京镭宝（Beamtech）Dawa / Nimma 系列固体激光器电源。界面沿用本项目位移平台软件的黑底、青色高亮工业控制风格，并按厂商资料实现 RS232 固定 10 字节协议。

## 已实现功能

- 自动枚举 Windows 串口，固定使用厂商要求的 `19200 / 8N1 / 无流控`
- 协议级仿真模式，不连接激光器即可测试完整流程
- 连接、联机、断开，以及联机成功时读取上传的电压和灯频率
- 本振电压（1-1000 V）、灯频率、分频系数设置
- 内时序、外时序且外部 Q、外时序且内部 Q 三种触发方式
- 预燃、工作、Q 开关的顺序控制与状态互锁
- 单次模式和单次激光触发
- 水流故障、门开关联锁故障上传帧识别、自动安全停机与软件锁定
- 一键安全停机，立即按“关 Q → 停工作 → 关预燃”顺序发送命令
- 关键参数仪表卡、实时状态链、3/3 安全确认进度和动态操作提示
- 收发帧实时监视与 CSV 日志导出
- 关闭窗口和安全断开时自动发送停机命令

## 运行环境

- Windows 10/11 x64
- Python 3.10 或更高版本（安装时需包含 Tkinter；官方 Windows Python 默认包含）
- USB 转 RS232 线及设备驱动
- 不需要第三方 Python 包

双击 `start_laser_control.bat`，或在本目录执行：

```powershell
python main.py
```

第一次运行请保持“仿真模式”勾选，连接后按顺序测试参数、预燃、工作、Q 输出和安全停机。仿真器灯频率初始值为 `20 Hz`。

## 实机操作

1. 确认激光器、电源、控制线、水路和安全联锁均按厂商手册正确连接，光路封闭，人员佩戴匹配波长的防护镜。
2. 开启钥匙开关，等待系统自检和冷却循环正常。
3. 在设备手控盒点击 `PC`，进入 PC 控制界面。
4. 用 USB 转 RS232 线连接电脑与电源的 PC 接口。
5. 取消“仿真模式”，选择串口，点击“连接并联机”。
6. 在激光器停止工作状态下设置电压、灯频率、分频系数和触发方式。频率不得超过该台激光器铭牌或合同约定的额定值。
7. 完成界面左侧三项安全确认后，依次开启预燃、工作和 Q 输出。
8. 正常关闭时依次关闭 Q、停止工作、关闭预燃，或直接点击“安全停机”，最后执行“安全断开”并关闭钥匙开关。

## 触发方式说明

- **内时序**：电源内部产生 CLK 与 Q 信号。内控工作时应拔掉外控信号线。
- **外时序（外部 CLK / Q）**：外部同时向 `CLK IN` 和 `Q IN` 输入信号。
- **外时序（外部 CLK，内部 Q）**：外部只提供 `CLK IN`，Q 信号由设备内部产生。
- 在“外部 CLK / Q”模式下，软件不会发送“开 Q”命令；开启工作后设备是否出光由外部 TTL 信号决定，界面显示 `EXTERNAL Q ARMED`。
- 外部输入按手册要求为 TTL 5 V 方波、50 Ω 匹配、带载电流不低于 50 mA、上升沿不大于 10 ns、脉宽不低于 10 μs。

## 安全限制

- 软件不能读取“水路正常”或“门已关闭”的正向状态；只有设备上报故障时才能识别。因此界面中的安全确认是操作员确认，不是硬件传感器读数。
- 收到水流或门联锁故障帧后，本次连接内禁止再次启动。排除故障并确认硬件安全后，重新连接设备。
- 参数修改在工作或 Q 输出期间被锁定。按厂商手册，必须停止工作后再修改参数。
- “安全停机”是串口命令，不替代硬件急停、钥匙开关或安全联锁。通信失效时应立即使用硬件急停或关闭钥匙开关。
- 厂商协议没有校验和，软件通过固定设备地址、固定 10 字节长度和帧尾 `CC 33 C3 3C` 验证接收数据。

## 协议依据

软件以 `电源串口通讯协议.doc`、`串口协议逻辑控制图 及示例操作11(1).docx` 和 `Dawa系列产品说明书通用版.pdf` 附件 I 为实现依据。示例中的 `V1H/V1L` 按 16 位大端整数处理，例如 680 V 为 `02 A8`；资料中个别逗号、句点及 `V2L` 为排版笔误，软件统一按重复出现且与示例一致的 10 字节格式解析。
