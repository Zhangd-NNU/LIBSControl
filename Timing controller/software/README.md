# LIBS 四通道时序控制器上位机

面向武汉华创智联光电 HCLDG_V3 / 时序控制器 V2.0 的 Windows 上位机。界面沿用本项目位移平台软件的黑底、青色工业仪器风格。

## 功能

- 自动枚举串口，使用厂商规定的 `115200 / 8N1` 连接
- 连续、固定脉冲数、外触发三种模式
- T1–T3 微秒与纳秒延时设置（纳秒步进 5 ns），T0 固定为时基零点
- 公共频率、脉宽和四通道 50 Ω / 高阻配置
- 参数更新、运行、停止，停止帧为 `DD DD`
- 发送帧实时十六进制预览和通信日志
- JSON 参数配置保存/加载
- 不连接硬件的仿真模式

## 安装与运行

Windows 10/11、Python 3.10+，无需安装第三方 Python 包：

```powershell
cd F:\Works\CodexMaterials\7-LIBSControl\1-时序控制器\software
python main.py
```

连接实机前，请先安装资料包中的 USB 转串口驱动。也可以直接勾选“仿真模式”熟悉全部功能。

## 协议实现说明

参数帧按厂商《HCLDG_V3 使用说明》逐字段编码：

```text
AA AA | 模式(1) | 脉冲数LE(2) | 频率整数/小数(2) | 脉宽LE(2)
      | T1 us LE(2)+ns LE(2) | T2(4) | T3(4) | 四路阻抗(4) | BB BB
```

说明书正文称参数区为“22 个字节”，但列出的字段合计为 23 字节，完整帧为 27 字节。本软件按全部字段实现。首次实机使用建议在示波器下低频测试，并对照界面通信日志确认设备固件所需帧长。
