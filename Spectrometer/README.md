# Maria 四通道光谱仪上位机

面向上海如海光电 Maria 四通道光谱仪的 Windows 上位机。程序直接调用资料包中的 **SeaSDK 1.2 x64 DLL**，同时提供不连接硬件的四通道仿真模式。

## 已实现功能

- USB 设备连接，以及 `型号@IP` 形式的网络设备连接
- 监听厂商 UDP 广播并自动填写网络设备（报文格式 `oceanmodule:型号,SN:序列号`，设备端口 `8888`）
- 四通道型号、序列号、像素数、波长范围和积分时间范围读取
- 积分时间、硬件平均、硬件/软件像素平滑、CCD 采集延迟统一设置
- 内触发、外触发、异步复位三种模式
- 单次、定次和连续采集；停止时调用 `seasdk_cancel_external_trigger` 解除外触发等待
- 四通道独立曲线、叠加显示，以及三种可选拼接方式：原始强度直接拼接、重叠区自动校正、标定系数拼接
- 暗谱采集、暗谱扣除、主峰标注、峰值和饱和度监视
- 光谱滚轮缩放、鼠标坐标读取、清除显示、最近 50 帧回看
- 手动或自动保存 UTF-8 CSV；未开启自动保存时仍可随时手动保存当前帧或选中的历史帧
- 清除显示只清空图表，不删除当前帧和历史记录，清除后仍可手动保存或从最近记录恢复

## 界面布局

- 左侧集中管理设备连接、曝光、平滑、延迟和触发参数。
- 中央以光谱图为主，顶部显示主峰波长、峰值强度、饱和度和采集速率；图表下方提供“清除显示”和“手动保存”，视图及拼接参数默认隐藏，点击“显示与拼接设置”后展开。
- 右侧负责单次、定次、连续、停止和暗谱采集；下方标签页分别查看通道状态、最近记录和数据保存。
- 快捷键：`F5` 单次采集，`Esc` 停止或取消外触发等待，`Ctrl+S` 保存当前帧。

## 运行

系统要求：Windows 10/11 x64、64 位 Python 3.10 或更高版本。

双击 `run.bat`，或在本目录执行：

```powershell
python main.py
```

首次使用请保持“仿真模式”勾选，连接后完成单次、暗谱、连续和保存流程测试。仿真模式无需驱动和硬件。

## 实机连接

### 驱动与 DLL

1. 从原始 `Maria四通道光谱仪使用说明书1.0.zip` 中安装 Oceanhood 新设备驱动。
2. 软件默认加载 `vendor/SeaSDK.dll`（SeaSDK 1.2，Windows 64 bit）。
3. 取消“仿真模式”后再连接。DLL 与 Python 位数必须一致；本软件按 64 位配置。

### USB

选择“USB”，点击“连接四通道”。程序依次打开 SDK 索引 0~3。Maria 正常应识别 4 个通道；少于 4 个时仍可采集已连接通道，但会弹出警告。

### 网络

1. 按厂商手册将电脑有线网卡设为 `24.5.10.100`，子网掩码 `255.0.0.0`。
2. 光谱仪通过网线连接电脑，并接好资料要求的 USB-A 连接和电源。
3. 选择“网络”，点击“扫描网络”。若没有收到广播，可手工填写，例如：

   `OH7020@24.5.10.30, OH7020@24.5.10.31, OH7020@24.5.10.32, OH7020@24.5.10.33`

   型号和 IP 应以设备实际广播/标签为准，不要机械照抄示例值。
4. 如扫描失败，检查网卡 IP、网线、Windows 防火墙和 UDP/TCP 端口 `8888`。

## LIBS 外触发操作建议

1. 先使用内触发并遮光，点击“采集并保存暗谱”。
2. 设置积分时间、采集延迟、平均次数，并“应用到全部通道”。Maria 资料给出的最短积分时间为 `6 μs`；软件还会读取各通道 SDK 实际上下限。
3. 选择“外触发（上升沿）”。触发信号必须是 **3.3 V 上升沿**；厂商资料明确警告 5 V 会损坏设备，建议脉宽 1~10 ms，勿长时间保持高电平。
4. 点击单次、定次或连续采集，软件进入等待状态。没有触发信号时，请使用“停止 / 取消外触发等待”，不要强制结束进程。
5. “异步复位”响应更快，但厂商说明其电子底噪会更高。

## CSV 格式

文件头以 `# key=value` 记录采集时间、帧号、积分时间、平均、平滑、延迟和触发模式。数据列为：

- `chN_wavelength_nm` / `chN_intensity_count`
- `stitched_wavelength_nm` / `stitched_intensity_count`

暗谱扣除仅影响显示和保存的处理后强度；原始数据在内存中的当前帧对象中保留，重新勾选/取消“显示时扣除暗谱”可切换处理。

## 拼接方式

- **原始强度直接拼接**：在相邻通道重叠区的中点切换通道，不改变任何被选中数据点的强度。适合核对原始计数和定量分析。
- **重叠区自动校正**：根据相邻通道重叠区的稳健中位比值自动缩放后续通道，减小接缝台阶。适合快速观察，但拼接强度可能不同于单通道强度。
- **标定系数拼接**：分别将 CH1～CH4 乘以用户输入的响应标定系数后拼接。默认系数均为 `1.0`；正式系数应由标准光源标定获得。

三种方式只改变拼接曲线，不修改界面中的四条单通道曲线。切换方式后当前帧会立即重新计算；CSV 文件头会记录 `stitch_mode` 和 `calibration_factors`。

## 安全说明

- 软件不能替代激光器硬件联锁、急停和防护眼镜。
- 连接或拆装模块前应关闭电源；设备工作环境按原厂资料为 0~40 ℃、相对湿度 5%~80%（25 ℃）。
- 本版本没有写 EEPROM、升级固件或控制激光器，避免误操作改变设备永久配置。
- SeaSDK 文档说明其代码并非线程安全；正常 SDK 调用在控制层串行化。外触发取消接口是为中断阻塞读取而设计，停止时会单独调用。
