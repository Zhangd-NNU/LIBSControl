# LIBS 位移平台扫描控制软件

适用于飞尼克斯（Feinixs）IMC 系列两轴位移平台。软件通过厂商 `ftcoreimc.dll` 控制地址为 `1`、`2` 的 X/Y 轴，并提供不连接硬件的仿真模式。

软件首次打开以及未连接设备时，X/Y/Z当前位置默认显示为 `0.000 mm`。实机连接并识别轴成功后，软件记录各轴的绝对编码器位置作为工作坐标原点；界面显示位置为“绝对位置−连接原点”，因此所有已连接轴可靠显示为 `0.000 mm`。绝对扫描命令会自动加回原点偏移，未连接轴自动忽略。

## 功能

- 从中心点开始逐圈向外扩展、覆盖完整内部区域的圆盘扫描
- 蛇形栅格扫描
- 圆盘半径、栅格纵向行数、栅格横向点数、径向/行间距、点间距、扫描速度和扫描点间停顿设置；位移尺寸单位为 mm，速度为 mm/s，停顿时间为 ms
- 路径预览、实时点位与进度显示、CSV 导出
- 串口（如 COM3/19200）或 TCP（IP/端口）连接
- 连接时自动识别1/2/3号轴的电机型号、位置、螺距、细分、速度和SDK软限位
- 不存在的轴自动禁用；X/Y轴未同时识别时禁止启动路径扫描
- 只识别到一个轴时仍允许连接、读取和手动控制该轴
- X/Y 扫描轴运动，以及 X/Y/Z 回零、当前位置置零和停止
- 回零和当前位置置零自动作用于所有已识别轴，未连接轴自动忽略
- X/Y/Z 三轴手动正负方向移动，可设置手动步长和手动速度
- 停止后可从未完成点继续扫描，也可将当前位置作为新起点重新扫描
- 软件限位检查；超限路径不能启动
- 手动移动和扫描过程中监测设备正负限位，达到极限时自动停止并弹出提示

## 运行

需要 Windows x64 和 Python 3.10+。默认通信波特率为 `115200`：

```powershell
python main.py
```

首次建议勾选“仿真模式”，生成路径并完整运行一次。实机运行时取消仿真，填写串口或控制器 IP。SDK DLL 默认使用项目 `vendor_reference` 中已解压的 x64 版本，也可在界面中修改。

## 实机使用前检查

1. 确认 X/Y 电机地址分别为 `1` 和 `2`，通讯参数与控制器一致。
2. 将软件限位设置为平台真实安全行程，并低速、小范围空载试运行。
3. 确保硬件急停和限位开关有效；软件“急停”只是通过通讯发送两轴停止命令。
4. 该IMC绝对编码器平台的厂商搜零接口无实际运动作用，因此软件“回零”会控制所有已识别轴真实移动到连接时记录的绝对位置；“当前位置置零”只重新定义软件工作原点。

圆盘和栅格都以点击“开始扫描”时读取到的平台当前位置作为第一个扫描点，无需设置中心 X/Y。圆盘将当前位置作为圆心，从中心点开始，按径向间距逐圈向外扩展，直到达到设定半径；每圈点数由周长和点间距自动计算。栅格从当前位置作为一个角点开始，按照设定的纵向行数和横向点数蛇形扫描；实际栅格高度为 `(纵向行数−1)×行间距`，宽度为 `(横向点数−1)×点间距`。预览和导出的 CSV 使用相对起点的位移，单位为 mm；真正开始扫描时软件将相对路径转换为实际坐标并进行软限位检查。扫描点驻留时间可用于 LIBS 激光触发或光谱采集的时间窗口，但当前版本未直接输出激光触发信号。

参考示例软件的运动参数，扫描速度默认值为 `10 mm/s`，扫描点间停顿默认值为 `0 ms`。停顿时间在程序内部转换为秒后执行。

参考配套软件的最大速度默认值，扫描速度和手动速度的软件安全上限均为 `10 mm/s`。输入更高速度时会弹出“速度过快”提醒并阻止运动，控制层也会再次拦截超速命令。
